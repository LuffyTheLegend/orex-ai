About Orex

Orex AI

Orex AI is a focused AI workspace with a polished glassy interface, fast Groq-powered replies, vision support for images, and richer file context for text, JSON, and code uploads.

Features

  • Vision support — Orex can see and discuss images you upload
  • Temporary chats — session-only, never saved to localStorage
  • Double-click any chat name to rename it inline
  • Settings modal with General, Memory, and Privacy tabs
  • Attach menu — files, research, quizzes, Wikipedia, dictionary
  • Research URLs — paste website links for Orex to visit and summarize
  • Wikipedia lookup — pull a real article summary into the chat
  • Dictionary lookup — real definitions, straight from the source
  • Multi-chat management with export (confirmation required) and delete
  • Groq-powered conversations with persistent local history
  • Rich markdown rendering + syntax-highlighted code blocks with copy buttons
  • Improved image prompt helper & research tools

Your API Key

Your Groq API key is saved only in your browser's localStorage. It is never sent anywhere except directly to Groq's official API when you send a message.

Chat History

All conversations are stored locally on your device. Orex AI has no backend server or database — your chats never leave your browser (except when sent to Groq for AI responses).

Memory

If enabled, Orex saves short facts it picks up from your chats (locally, in your browser only) and reuses them in future conversations. You can review or delete them anytime in the Memory tab, or turn the feature off entirely.

No Tracking

Orex AI does not use analytics, cookies, or any third-party tracking. No personal data is collected or transmitted by Orex AI itself.

Groq's Policy

Messages you send are processed by Groq's API. Review Groq's Privacy Policy for details on how they handle your data.

Temporary Chats

Chats marked as temporary are kept in memory only for the current session and are automatically removed when you close or refresh the page.
