About Orex

Orex AI

Orex AI is a focused AI workspace with a polished glassy interface, fast Groq-powered streaming replies, vision support for images, file context, and a suite of research tools — all running client-side in a single file.

Features

  • Streaming responses with a Stop button and regenerate
  • Vision support — Orex can see and discuss images you upload
  • Text & code file attachments read straight into context
  • Temporary chats — session-only, never saved to localStorage
  • Double-click any chat name to rename it inline
  • Memory — Orex quietly learns facts about you across chats
  • Research URLs, Wikipedia lookup, dictionary, quizzes
  • Image generation, markdown + syntax-highlighted code with copy buttons
  • Multi-chat management with JSON export and light/dark themes

Your API Key

Saved only in your browser's localStorage. It is never sent anywhere except directly to Groq's official API when you send a message.

Chat History

All conversations are stored locally on your device. Orex AI has no backend server or database — your chats never leave your browser (except when sent to Groq for responses).

Memory

If enabled, Orex saves short facts it picks up from your chats (locally, in your browser only) and reuses them later. Review or delete them anytime in the Memory tab, or turn the feature off.

No Tracking

Orex AI does not use analytics, cookies, or any third-party tracking. No personal data is collected or transmitted by Orex AI itself.

Groq's Policy

Messages you send are processed by Groq's API. Review Groq's Privacy Policy for details.

Temporary Chats

Chats marked as temporary are kept in memory only for the current session and are removed when you close or refresh the page.
